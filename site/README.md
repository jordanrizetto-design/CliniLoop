# Site público da Loop University

Publicado pelo Worker `loopuniversity-site` (Cloudflare Workers Builds, Root directory = `site`).

- `public/index.html`: página da marca, em loopuniversity.com.br
- `public/cliniloop/index.html`: página de vendas do Sistema Loop, em loopuniversity.com.br/cliniloop/
- `public/assets/`: imagens e logotipos

Na página de vendas, no fim do arquivo: `CHECKOUT_URL` (link de pagamento da Hotmart), `YOUTUBE_ID` e `YOUTUBE_ID_ETAPAS` (vídeos) e `DEPOIMENTOS_APROVADOS`.
